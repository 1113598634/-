如何让全家族打开网址都看到最新修改？

💡 为什么别人打开网址看到的还是初始画面？

因为普通静态网页（GitHub + Vercel）没有连接后台数据库时，您添加的族人默认自动保存在您自己手机/电脑的浏览器缓存里。要让全家族所有人打开网址都看到您修好的最新族谱，请任选以下两种方式之一：

方法一（最推荐 · 永久免费免配置）

一键下载「已内嵌最新族谱数据与密码」的 index.html

点击下方按钮，系统会把您当前修好的全部族谱节点、世系排布以及您设置的管理员密码直接写进一个新的 index.html 文件里下载下来。
您只需把这个新的 index.html 上传替换到您的 GitHub 仓库，Vercel 会在 10 秒内自动更新！此后任何人用任何手机打开网址，看到的默认画面就是您修好的最新族谱（且处于只读保护状态，只有您能用密码修改）！

方法二（进阶 · 云端免上传实时同步）

绑定 JSONBin.io 免费云端数据库（改完自动全网同步）

如果您不想每次大修后替换 GitHub 文件，可在 jsonbin.io 免费创建一个 Bin，将 Bin ID 和 Access Key 填在下方，然后再点一次上方「生成 index.html」上传。之后您在网页上的任何修改点击「推送至云端」，全家族刷新网页即可秒级同步！
